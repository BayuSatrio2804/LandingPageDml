# DML Corporate, Plan 2: Fondasi Payload dan Halaman Statis Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Memasang fondasi Payload 3 (Postgres, admin panel, collection `users`/`media`/`inquiries`) di dalam project Next.js yang sudah ada, lalu membangun tiga halaman yang belum diklaim plan lain: `/kontak` (form lead tersimpan ke Payload sebelum redirect WhatsApp), `/tentang-kami` (silsilah dan profil), `/karier` (empty state siap JSON-LD).

**Architecture:** `app/` dipecah jadi route group `(site)` untuk halaman publik dan `(payload)` untuk admin panel, supaya admin panel tidak mewarisi header/footer/motion provider situs. Payload hidup di `src/payload/` dan diakses dari Next lewat Local API (`getPayload`), bukan lewat REST, karena pemanggilnya adalah server action di aplikasi yang sama. Form lead punya satu infrastruktur bersama di `features/inquiry/` (schema zod, rate limiter, server action) yang dipakai `/kontak` sekarang dan form Permintaan Informasi Bisnis di Plan 3 nanti.

**Tech Stack:** Next.js 16.2+ App Router (sudah terpasang), Payload 3.73+, `@payloadcms/db-postgres`, `@payloadcms/richtext-lexical`, PostgreSQL 16 lewat Docker Compose, react-hook-form 7.x, zod 4.x, `@hookform/resolvers`, sharp, Vitest, Playwright, `@axe-core/playwright`, bun.

**Spec:** `docs/superpowers/specs/2026-08-16-dml-corporate-design.md` dan `docs/superpowers/specs/2026-08-17-dml-plan-2-design.md`.

## Global Constraints

Setiap task secara implisit tunduk pada seluruh isi bagian ini. Baris bertanda (Plan 1) sudah berlaku sejak plan sebelumnya dan tetap mengikat; baris bertanda (Plan 2) baru untuk plan ini.

- **Next.js minimum 16.2.0, bun sebagai satu-satunya package manager.** (Plan 1)
- **Bahasa situs Indonesia saja**, `lang="id"`, tidak ada i18n. (Plan 1)
- **Halaman dark-locked**, tidak ada `dark:` variant atau theme toggle. (Plan 1)
- **Teks di atas `--color-accent` selalu `--color-on-accent`.** Kombinasi `--color-ink` di atas `--color-accent` dilarang, 2,72:1. (Plan 1)
- **Radius: 12px kartu dan panel, 8px input, full-pill tombol.** (Plan 1)
- **Ikon hanya `@phosphor-icons/react`, `weight="regular"`.** (Plan 1)
- **Dilarang `window.addEventListener('scroll')`.** Gunakan `IntersectionObserver` atau ScrollTrigger. (Plan 1)
- **Dilarang menyimpan nilai kontinu di React state.** (Plan 1)
- **Setiap `useEffect` yang membuat side effect lintas-render wajib punya cleanup.** (Plan 1)
- **Tidak ada em dash (`—`) atau en dash (`–`)** di teks yang terlihat pengguna maupun komentar kode. Gunakan tanda hubung biasa. (Plan 1)
- **Konten teks dan link selalu render di server.** Client leaf hanya boleh mengubah transform, opacity, atau state interaktif elemen yang sudah ada di HTML. (Plan 1)
- **Semua angka perusahaan yang belum dikonfirmasi klien ditandai** `// unverified: <sumber>` di file data, `{/* unverified: <sumber> */}` di titik render JSX. Jangan menambah entri berisi tanggal atau angka yang tidak ada di sumber manapun. (Plan 1)
- **Setiap task wajib lolos `bun run lint`, `bunx tsc --noEmit`, `bun run test`, dan `bun run build`** sebelum commit. (Plan 1)
- **`noUncheckedIndexedAccess` aktif.** Akses indeks array/Record menghasilkan `T | undefined`; perbaiki dengan guard eksplisit, bukan `!` atau `as`. (Plan 1)
- **Payload minimum 3.73, Postgres 16.** Jangan menurunkan versi ini. (Plan 2)
- **CMS hanya untuk lead (`inquiries`) di plan ini.** Halaman korporat (`/kontak`, `/tentang-kami`, `/karier`) tetap hardcoded di `src/content/`, bukan collection Payload. Collection `posts` bukan scope plan ini. (Plan 2)
- **Validasi form wajib dijalankan ulang di server action**, bukan hanya di client. Validasi client adalah UX, bukan boundary keamanan. (Plan 2)
- **Setiap form lead wajib punya honeypot dan rate limit per IP** sebelum submission tersimpan. (Plan 2)
- **Tidak ada iframe atau script pihak ketiga** (peta, chat widget) yang dimuat di halaman manapun. Tautan keluar cukup lewat `<ExternalLink>`. (Plan 2)

```ts
type RateLimitEntry = { count: number; windowStart: number };

/**
 * In-memory, bukan Postgres-backed. Deployment adalah satu container tanpa
 * horizontal scaling (spec bagian 15), jadi state yang reset saat restart
 * adalah tradeoff yang diterima untuk form lead bervolume rendah, bukan
 * kelalaian.
 */
export function createRateLimiter({
  limit,
  windowMs,
}: {
  limit: number;
  windowMs: number;
}): { check(key: string): boolean } {
  const store = new Map<string, RateLimitEntry>();

  return {
    check(key: string): boolean {
      const now = Date.now();
      const entry = store.get(key);

      if (!entry || now - entry.windowStart >= windowMs) {
        store.set(key, { count: 1, windowStart: now });
        return true;
      }

      if (entry.count >= limit) return false;

      entry.count += 1;
      return true;
    },
  };
}
```

```ts
"use server";

import { headers } from "next/headers";
import { getPayload } from "payload";
import config from "@payload-config";
import { inquirySchema } from "./schema";
import { createRateLimiter } from "./rate-limit";

const rateLimiter = createRateLimiter({ limit: 5, windowMs: 10 * 60 * 1000 });

export async function submitInquiry(
  input: unknown,
  source: string,
): Promise<{ ok: true } | { ok: false; error: string }> {
  const parsed = inquirySchema.safeParse(input);
  if (!parsed.success) {
    return { ok: false, error: "Periksa kembali isian form." };
  }

  // Honeypot terisi berarti bot. Client tetap menerima respons sukses palsu
  // supaya bot tidak belajar field mana yang jadi jebakan.
  if (parsed.data.website) {
    return { ok: true };
  }

  const requestHeaders = await headers();
  const ip = requestHeaders.get("x-forwarded-for")?.split(",")[0]?.trim() ?? "unknown";

  if (!rateLimiter.check(ip)) {
    return { ok: false, error: "Terlalu banyak percobaan, coba lagi nanti." };
  }

  const payload = await getPayload({ config });
  await payload.create({
    collection: "inquiries",
    data: {
      name: parsed.data.name,
      phone: parsed.data.phone,
      email: parsed.data.email,
      message: parsed.data.message,
      source,
    },
  });

  return { ok: true };
}
```

`split(",")[0]?.trim() ?? "unknown"` menangani `noUncheckedIndexedAccess`: `x-forwarded-for` bisa berisi rantai proxy dipisah koma, dan hasil `.split(",")[0]` tetap `string | undefined` di TypeScript meski secara runtime array split tidak pernah kosong.

```tsx
"use client";

import { useEffect, useRef, useState } from "react";

export function AnchorNav({ items }: { items: { id: string; label: string }[] }) {
  const [activeId, setActiveId] = useState(items[0]?.id);
  const observerRef = useRef<IntersectionObserver | null>(null);

  useEffect(() => {
    const sections = items
      .map((item) => document.getElementById(item.id))
      .filter((el): el is HTMLElement => el !== null);

    const observer = new IntersectionObserver(
      (entries) => {
        for (const entry of entries) {
          if (entry.isIntersecting) setActiveId(entry.target.id);
        }
      },
      { rootMargin: "-40% 0px -50% 0px" },
    );
    observerRef.current = observer;
    for (const section of sections) observer.observe(section);

    return () => observer.disconnect();
  }, [items]);

  return (
    <nav aria-label="Navigasi halaman" className="sticky top-20 flex gap-6 border-b border-surface-3 pb-3">
      {items.map((item) => (
        <a
          key={item.id}
          href={`#${item.id}`}
          aria-current={activeId === item.id ? "true" : undefined}
          className={
            activeId === item.id
              ? "text-sm font-medium text-accent"
              : "text-sm font-medium text-ink-muted hover:text-ink"
          }
        >
          {item.label}
        </a>
      ))}
    </nav>
  );
}
```

`IntersectionObserver` dipakai sesuai Global Constraints (dilarang `window.addEventListener('scroll')`). `rootMargin: "-40% 0px -50% 0px"` membuat section terhitung "aktif" saat berada di pita tengah viewport, bukan cuma saat baru muncul di tepi bawah.

```ts
test("tidak ada elemen dengan latar aksen yang memakai teks ink", async ({
  page,
}) => {
  for (const path of ["/", "/kontak", "/tentang-kami", "/karier"]) {
    await page.goto(path);

    const violations = await page.evaluate(
      ({ accent, ink }) => {
        function effectiveBackgroundColor(start: Element): string {
          let node: Element | null = start;
          while (node) {
            const bg = getComputedStyle(node).backgroundColor;
            if (bg !== "rgba(0, 0, 0, 0)" && bg !== "transparent") return bg;
            node = node.parentElement;
          }
          return "rgba(0, 0, 0, 0)";
        }

        const bad: string[] = [];
        for (const el of Array.from(document.querySelectorAll("*"))) {
          const style = getComputedStyle(el);
          if (style.color === ink && effectiveBackgroundColor(el) === accent) {
            bad.push(el.tagName + "." + String(el.className));
          }
        }
        return bad;
      },
      { accent: ACCENT, ink: INK },
    );

    expect(violations, `route ${path}`).toEqual([]);
  }
});
```
